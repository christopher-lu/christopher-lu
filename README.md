### 📱 DIDT — Did I Do That · Alpha

A mobile-first habit-tracking and personal-growth application. Development now spans three repositories:

[![Mobile](https://img.shields.io/badge/DIDT-Mobile-0F766E?style=flat-square&logo=expo)](https://github.com/christopher-lu/DIDT-mobile)
[![Backend](https://img.shields.io/badge/DIDT-Backend-0F766E?style=flat-square&logo=nestjs)](https://github.com/christopher-lu/DIDT-backend)
[![Web](https://img.shields.io/badge/DIDT-Web-0F766E?style=flat-square&logo=nextdotjs)](https://github.com/christopher-lu/DIDT-web)

**Progress:** Backend and mobile Alpha Stabilization complete; mobile Alpha Polish in progress. The companion web client has an established foundation and backend-integrated authenticated experiences. This is **not yet a public production launch**.

- **Mobile:** React Native, Expo Router, TypeScript; authentication, habit/category management, Today tracking, calendar history, and theme customization
- **Backend:** NestJS, Prisma, PostgreSQL; authoritative scheduling, occurrence snapshots, lifecycle recovery, tracking commands, and analytics
- **Web:** Next.js App Router, React, TypeScript, TanStack Query, Vitest; authenticated shell, secure refresh-cookie architecture, and backend-driven Today interactions
- **Quality:** Automated regression suites, real-PostgreSQL backend E2E tests, iOS/Android runtime checks, and browser-focused verification

**Engineering approach:** Keep domain rules authoritative on the backend while mobile and web clients handle presentation, interaction, and client caching. Preserve historical tracking correctness and make destructive actions recoverable.
